* Lo que hace su funcionamiento es que al tener una base de datos virtual en java el traspaso de información a un SGBD pasa por los drivers específicos convirtiendo el código java en el lenguaje SQL especifico de ese SGBD, en las dependencias deberá añadir el driver del SGBD que desea y luego en el aplication.properties añadir los campos relacionados al schema, password, user, la url y el driver-class-name.



* La ventaja que aporta es que java se encarga de hacer muchos procesos por detrás que anteriormente se deberían de configurar y picar a mano, el caso que yo me he dado cuenta son los constructores del record necesarios en los response y los request.
